# card-catalog Pro

- **Team sign-in**: people sign in with Google, Microsoft, GitHub or any OpenID provider, each with a role (reader, filer, admin), and clients that only speak OAuth can connect.
- **Many libraries**: separate catalogs (work, home, one per client) from one deployment, each with its own access and its own numbering.
- **Nightly chop**: each night, finished chats and call transcripts are cut into numbered cards with blurbs and tags and filed on the right shelf.
- **Agent work queue**: scheduled agents wake up, take one job from a shared queue, report what they did and clock out, with leases so two agents never take the same job.
- **Usage reports**: which questions your agents ask, which cards they read, and which cards nobody reads, from records kept in your own database.
- **Snowflake-native version**: the same catalog running inside your own Snowflake account, with Snowflake roles deciding who reads what.
